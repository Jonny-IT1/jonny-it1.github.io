ContextCraft is a next-gen codebase context packer and visual token budgeter. It scans repositories, strips them down to AST signatures and packs clean, token-optimized prompts — via a fast CLI, a sleek web dashboard or a Python SDK.

Key features

Every token, accounted for

AST signature pruning

Extract class and function signatures while stripping implementation bodies — saving 70% to 90% of tokens per prompt.

Real-time token budgeting

Accurate per-file token counts keep every prompt inside your model's context window. Never hit a limit unexpectedly again.

Git-diff mode

Pack only modified or staged files for focused, diff-driven prompts — ideal for code reviews and incremental tasks.

Dual interface

A lightning-fast CLI for scripting plus a sleek dark-mode web dashboard for exploring token budgets interactively.

Git-aware filtering

Respects .gitignore and automatically filters binaries and build artifacts, so only meaningful source reaches the prompt.

Multi-format output

Emit prompts as Markdown, structured XML with file paths, or machine-readable JSON — whatever your pipeline expects.

Interfaces

Three commands. That's it.

Everything ContextCraft does is one command away — and every command is also a Python function when you need it inside your own agents and workflows.

pack

Pack the codebase into a single AI-ready context prompt, with flags for format, signature pruning, git-diff and token limits.

stats

Display a full token breakdown table of the codebase before packing anything.

ui

Launch the local interactive web dashboard for visual token budgeting.

import contextcraft

# Pack a repo into a token-optimized prompt
prompt = contextcraft.pack_codebase(
    root_dir="./my_project",
    output_format="markdown",  # md | xml | json
    signatures_only=True,         # AST pruning
    max_tokens=100000,
)

# Repo token stats
stats = contextcraft.get_codebase_stats("./my_project")
print(stats["total_estimated_tokens"])
