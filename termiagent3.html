Key features

An agent that actually acts

Universal providers

Connect frontier clouds or run fully offline with Ollama, vLLM, LM Studio and Jan. Modern, legacy and vision models are all in the catalog.

Multimodal vision

Drop screenshots, diagrams and UI mockups into the conversation and let vision models understand them natively.

Image generation

A native generate_image tool produces diagrams, mockups and visual assets straight from text prompts.

Live model switching

Switch the active model mid-conversation with a single slash command — cloud to local and back, without losing context.

Autonomous tools

view_file, write_file, edit_file, search_codebase, generate_image and run_shell_command — a complete toolbelt for real work.

Python SDK inside

Import the agent into your own Python projects and run turns programmatically — the CLI is only the beginning.

Usage

Chat, command, or script

Start an interactive Rich-powered REPL in your project directory, or fire a single instruction from the command line and let the agent work.

termiagent

Start the interactive chat mode in any project directory.

termiagent -p "…"

One-shot mode: run a single instruction directly from the command line.

/model /clear /history /help /exit 
from termiagent import TermiAgent, UniversalLLMProvider

# 1. Pick any provider - cloud or local
provider = UniversalLLMProvider(
    model_name="gemini/gemini-2.0-flash"
)

# 2. Instantiate the agent in a target directory
agent = TermiAgent(provider=provider, work_dir="./my_project")

# 3. Execute a turn programmatically
response = agent.run_turn("Refactor main.py to use async functions")
print("Agent response:", response)
