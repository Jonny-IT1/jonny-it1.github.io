The Tools

Two tools, one philosophy

Feed large language models exactly what they need — nothing more, nothing less. Pack context with precision, then let an autonomous agent act on it.

ContextCraft

A next-gen codebase context packer and visual token budgeter. It scans repositories, prunes them down to AST signatures and packs clean, token-optimized prompts for any LLM — via CLI, web dashboard or Python SDK.

AST pruning token budgeting git-diff mode Markdown · XML · JSON
View details

TermiAgent

A universal terminal AI coding agent. It reads and edits files, searches the codebase, runs shell commands and generates images — powered by any cloud provider or a fully local LLM.

Highlights

Built for the AI-native workflow

Surgical token control

Count every token before you spend it. Real-time budgeting keeps prompts inside any model's context window, with no surprises.

Zero lock-in

Cloud frontier models or 100% local weights via Ollama, vLLM, LM Studio and Jan. Switch the active model live, mid-conversation.

CLI-first, SDK-ready

Both tools ship as fast CLIs and clean Python libraries. Import them into your own agents, pipelines and workflows.

Git-aware by design

Respects .gitignore, filters binaries automatically and can pack only what changed — perfect for focused, diff-driven prompts.

Autonomous actions

Read, write and edit files, regex-search the codebase, run tests and shell commands, generate diagrams — all inside one REPL.

Multimodal vision

Screenshots, diagrams and UI mockups go straight into the conversation with vision-capable models for true visual understanding.
